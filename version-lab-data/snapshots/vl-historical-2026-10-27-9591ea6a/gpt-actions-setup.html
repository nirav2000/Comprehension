Use GPT Actions with Comprehension

What GPT Actions can do

A Custom GPT can call the same Cloudflare marking model on an answer you provide in ChatGPT. This does not read your ChatGPT conversation from the website, and it does not automatically import the answer into Firebase.

Set up your Custom GPT

In ChatGPT, go to GPTs → Create → Configure → Actions → Import from URL. Use this OpenAPI schema:

gpt-actions-openapi.yaml

Choose authentication: API Key → Bearer. Supply a long randomly generated bearer token matching the private GPT_ACTION_TOKEN Worker secret. Do not put it in GitHub or the GPT instructions.

Then in GPT instructions: “Use coachEnglishAnswer only after I supply an exam question, a quotation and an answer. Ask one small follow-up question before showing a full model answer. Explain the meaning and evidence, not just mark an exact phrase.”

Before Actions can work

The Cloudflare Worker must be deployed and the token installed. Its URL must return a healthy result. If GPT Actions is unavailable in your workspace, Ask ChatGPT from Answer Ladder still works by copying a prepared prompt.
