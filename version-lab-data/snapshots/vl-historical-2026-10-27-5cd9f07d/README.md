# Comprehension Coach

A lightweight 11+/12+ comprehension training app focused on exam technique rather than simply completing full papers.

## Core method

1. **Decode** the question into **ACTION + TARGET**.
2. **Collect** only evidence that directly answers the target.
3. **Scaffold** the thinking using arrows and short notes.
4. **Write** a concise answer, then compare it with a model.

The app includes mixed and skill-specific practice for:
- language analysis
- inference
- judgement
- retrieval/comparison
- creative continuation

It also includes worked examples, reusable scaffold patterns, timers, and local progress tracking.

## Run

Open `index.html` directly, or enable GitHub Pages for the repository using the `main` branch root.
